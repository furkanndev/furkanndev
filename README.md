### `02 · FLAGSHIPS` &mdash; Production Desktop Workstations

#### 01 / AuraPDF Pro &mdash; `High-Performance Desktop PDF Workstation`

> *"Acrobat-grade precision without telemetry, subscriptions, or bloat."*

Adobe Acrobat-grade desktop PDF workstation built for speed, offline privacy, and intensive document workflows. Built solo &mdash; from direct in-page text stream modification to low-latency PyMuPDF C++ rendering to the standalone Inno Setup 6 packaging pipeline.

* **Direct On-Canvas Editing:** Select, mutate, re-font, resize, and reflow text blocks directly on PDF pages in real time without external conversion.
* **Sandwich OCR Engine:** Coordinate-aligned searchable text layer generated beneath bitmap scans without visual degradation.
* **Document Conversion Pipelines:** Automated export to Microsoft Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), and reflowable `.epub`.
* **Security & Form Serialization:** Stylus signatures, official PNG stamps, bidirectional AcroForms, Bates numbering, and permanent black-out redaction.
* **Production Packaging:** Standalone single-click installer (`.exe`) compiled via Inno Setup 6 with complete embedded runtime dependencies.

`Python 3.10+` &bull; `PyQt6 Native` &bull; `PyMuPDF C++ Engine` &bull; `ONNX / RapidOCR` &bull; `Inno Setup 6` &bull; `Win64`  
&rarr; **[View AuraPDF Pro Repository](https://github.com/furkanndev/AuraPDF)**

#### 02 / Keystone &mdash; `Automated Windows Deployment & Optimization Platform`

> *"Zero-friction workstation onboarding for fresh Windows 10 & 11 environments."*

Unified post-installation Windows workstation setup suite, package deployment engine, and registry optimization platform. Automates hours of manual configuration into a single declarative operation.

* **140+ Silent Deployments:** Automated silent package retrieval across essential developer toolchains, runtimes, and utilities via Winget integration.
* **Validated Registry Tweaks:** Reclaims taskbar end-task, legacy context menus, and debloats telemetry with real-time `[Active]/[Disabled]` inspection and 1-click rollback.
* **Pre/Post-Format Migration:** Exports browser bookmarks, Wi-Fi passwords, SSH keys, `.gitconfig`, PowerShell profiles, and VS Code configurations into executable deployment manifests.
* **Multi-Profile Isolation:** Independent workspace configurations (`Developer Setup`, `Gaming Rig`, `Clean Workstation`) with portable persistence.

`Python 3.11+` &bull; `PyQt6` &bull; `Win32 API` &bull; `Winget Integration` &bull; `Windows Registry` &bull; `PyInstaller` &bull; `Win64`  
&rarr; **[View Keystone Repository](https://github.com/furkanndev/KeyStone)**
