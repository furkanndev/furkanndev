### Featured Engineering Works

#### [AuraPDF](https://github.com/furkanndev/AuraPDF) — Modern Windows Desktop PDF Platform
> **Stack:** `Python 3.10+` &bull; `PyQt6 / Qt` &bull; `PyMuPDF` &bull; `RapidOCR / ONNX` &bull; `Inno Setup 6` &bull; `PyInstaller`

A comprehensive, multi-tabbed desktop PDF productivity platform engineered for power users, legal/academic workflows, and office environments.
- **Direct Page Text Modification:** Interactive selection, real-time font mutation, and text block reflow directly within rendered PDF canvases.
- **Native Document OCR:** Integrated offline OCR engine extracting text streams from scanned pages via ONNX inference.
- **Comprehensive Document Toolbox:** Multi-document split, merge, lossless visual compression, sensitive data redaction, and encryption.
- **Automated Distribution:** Turnkey build system producing standalone, production-ready Windows installers (`.exe`) with custom setup wizards.

#### [Social-Saver](https://github.com/furkanndev/Social-Saver) — Anonymous Media Extraction Engine
> **Stack:** `Python` &bull; `Flask` &bull; `Web API Reverse Engineering` &bull; `Session Interception` &bull; `Streaming Compression`

A specialized utility engineered to inspect, stream, and archive full-resolution profile media and stories without leaving audit trails.
- **Zero-Beacon Direct Streaming:** Bypasses telemetry endpoints by intercepting edge CDN media streams (`seen = false`).
- **Automated Authentication:** Built-in webview window captures session credentials and CSRF tokens automatically, eliminating manual token extraction.
- **Archive Pipeline:** High-throughput streaming ZIP packaging for instant bulk story downloads.

#### [NavalStrike](https://github.com/furkanndev/NavalStrike) — Decoupled 2D Arcade Simulation Engine
> **Stack:** `C#` &bull; `.NET Framework` &bull; `Windows Forms` &bull; `Object-Oriented Design (OOD)`

An interactive naval combat simulation developed to demonstrate strict separation of concerns and object-oriented architecture.
- **Clean Decoupled Architecture:** Strict separation between the game engine library (`Savas.Library`) and presentation viewport (`Savas.Desktop`).
- **OOP Patterns:** Interface segregation (`IHareketEden`), polymorphic entity hierarchies, bounding-box collision detection, and event-driven timers.
- **State Persistence:** Binary/text score serialization with high-score tracking and dynamic difficulty scaling.

#### [DirectoryChangeMonitorService](https://github.com/furkanndev/DirectoryChangeMonitorService) — Kernel-Level Linux Auditing Daemon
> **Stack:** `Bash` &bull; `Linux Kernel inotify` &bull; `Systemd` &bull; `POSIX Automation`

A Linux background daemon auditing real-time filesystem mutations using low-overhead kernel event hooks.
- **Kernel Event Trapping:** Zero-polling event loops via `inotifywait` (`modify`, `attrib`, `close_write`, `move`, `create`, `delete`).
- **Systemd Supervision:** Production service unit configuration supporting boot autostart, auto-restart, and journal logging.

#### [MatrixManipulator](https://github.com/furkanndev/MatrixManipulator) — Linear Algebra & Transformation Engine
> **Stack:** `Modern C++17` &bull; `Standard Template Library (STL)` &bull; `Algorithmic Optimization`

A high-performance C++ utility implementing matrix algebra algorithms and coordinate permutations.
- **Matrix Operations:** In-place coordinate scalar swaps ($A_{ij} \longleftrightarrow B_{ij}$) and classical dot product computation ($O(n^3)$).
- **Memory Safety:** Strict bounds checking and modular algorithmic routines.

### Engineering Standards

- **Performance-First Mindset:** Sub-millisecond response times, low RAM footprints, and direct C/C++ engine utilization (PyMuPDF, STL).
- **Decoupled Architecture:** Strict boundary lines separating domain algorithms, UI presentation, and persistence logic.
