### Overview

> *"Simplicity is the ultimate sophistication. Software should perform with sub-millisecond precision, respect hardware constraints, and ship as a seamless, turnkey product."*

I am **Furkan Gültekin**, a **Software Developer** dedicated to native desktop application architecture, low-latency document processing, and deep-level systems automation. My focus is engineering end-to-end software—spanning low-level C/C++ memory models, fluid Qt6 desktop user experiences, local ONNX OCR pipelines, and automated standalone Windows installer production (`.exe` via Inno Setup 6).

### The Product Lineup

#### [AuraPDF](https://github.com/furkanndev/AuraPDF) &bull; *The Desktop PDF Suite. Redefined.*
> **Pro workflows. Sub-second latency. Native intelligence.**

<p>
  <img src="https://img.shields.io/badge/Version-Basic%20v1.1-1d1d1f?style=flat-square" />
  <img src="https://img.shields.io/badge/Platform-Windows%2010%20%2F%2011-0078D6?style=flat-square&logo=windows11&logoColor=white" />
  <img src="https://img.shields.io/badge/Engine-PyMuPDF%20(C)-D9381E?style=flat-square" />
  <img src="https://img.shields.io/badge/GUI-PyQt6-41CD52?style=flat-square&logo=qt&logoColor=white" />
  <img src="https://img.shields.io/badge/Packaging-Inno%20Setup%206-1d1d1f?style=flat-square" />
</p>

A multi-tabbed, lightweight Windows desktop PDF suite engineered for power users, legal/academic workflows, and offices without cloud dependency.
- **In-Page Text Editing:** Interactive selection, font mutation, and character reflow directly on rendered PDF canvases in real time.
- **Offline OCR Pipeline:** Scanned document text extraction powered by local ONNX inference models with zero external network transmission.
- **Complete PDF Toolbox:** Multi-document merge, split, high-ratio compression, visual redaction, and cryptographic password encryption.
- **Automated Distribution:** Turnkey compilation scripts generating signed, single-click Windows installers (`.exe`).

---

#### [Social-Saver](https://github.com/furkanndev/Social-Saver) &bull; *Media Preservation. Untracked.*
> **Direct CDN streaming. Zero telemetry. Instant bulk archival.**

<p>
  <img src="https://img.shields.io/badge/Version-v1.0-1d1d1f?style=flat-square" />
  <img src="https://img.shields.io/badge/Stack-Python%20%2F%20Flask-3776AB?style=flat-square&logo=python&logoColor=white" />
  <img src="https://img.shields.io/badge/Telemetry-Bypassed-30D158?style=flat-square&labelColor=1d1d1f" />
  <img src="https://img.shields.io/badge/Pipeline-Streaming%20ZIP-blue?style=flat-square" />
</p>

An archival research utility engineered to stream and preserve ephemeral stories, highlights, and original-resolution profile avatars without triggering read-receipt telemetry.
- **Zero-Beacon Direct Streaming:** Bypasses client-facing telemetry endpoints by intercepting edge CDN media streams directly (`seen = false`).
- **Automated Credential Ingestion:** Features an isolated webview window that captures authenticated session cookies and CSRF tokens automatically.
- **High-Throughput Archival Pipeline:** An in-memory streaming ZIP packaging mechanism that bundles user media batches into instant downloadable archives.

#### [NavalStrike](https://github.com/furkanndev/NavalStrike) &bull; *Clean Architecture in Motion.*
> **Decoupled domain logic. Deterministic game loop.**

<p>
  <img src="https://img.shields.io/badge/Stack-C%23%20%2F%20.NET-239120?style=flat-square&logo=csharp&logoColor=white" />
  <img src="https://img.shields.io/badge/Architecture-Decoupled%20OOD-blue?style=flat-square" />
  <img src="https://img.shields.io/badge/Performance-60%20FPS%20Loop-30D158?style=flat-square&labelColor=1d1d1f" />
</p>

A naval combat arcade simulation built to demonstrate strict object-oriented design and SOLID separation of concern.
- **Decoupled Architecture:** Clean separation between domain library (`Savas.Library`) and presentation layer (`Savas.Desktop`).
- **OOP Design:** Interface-driven contracts (`IHareketEden`), polymorphic entity hierarchies, and bounding-box collision detection.
- **State Persistence:** Binary/text score serialization with high-score tracking and dynamic difficulty scaling.

---

#### [DirectoryChangeMonitorService](https://github.com/furkanndev/DirectoryChangeMonitorService) &bull; *Kernel-Level Filesystem Intelligence.*
> **Zero polling. Pure event-driven daemon.**

<p>
  <img src="https://img.shields.io/badge/OS-Linux%20Kernel%20inotify-FCC624?style=flat-square&logo=linux&logoColor=black" />
  <img src="https://img.shields.io/badge/Supervisor-Systemd-1d1d1f?style=flat-square" />
  <img src="https://img.shields.io/badge/Overhead-Zero%20Polling-30D158?style=flat-square&labelColor=1d1d1f" />
</p>

A Linux background daemon auditing real-time filesystem mutations using low-overhead kernel event hooks via `inotifywait` across six POSIX event masks under a managed `systemd` service unit.

---

#### [MatrixManipulator](https://github.com/furkanndev/MatrixManipulator) &bull; *High-Performance Linear Transformations.*
> **Modern C++17. Zero heap allocations.**

<p>
  <img src="https://img.shields.io/badge/Language-Modern%20C%2B%2B17-00599C?style=flat-square&logo=c%2B%2B&logoColor=white" />
  <img src="https://img.shields.io/badge/Optimization-O(n%5E3)%20Classical%20Dot-blue?style=flat-square" />
  <img src="https://img.shields.io/badge/Memory-Strict%20Bounds-30D158?style=flat-square&labelColor=1d1d1f" />
</p>

A high-speed C++ utility implementing in-place coordinate scalar permutations ($A_{ij} \longleftrightarrow B_{ij}$) and classical matrix dot product calculations with strict memory safety and zero heap reallocation overhead.
